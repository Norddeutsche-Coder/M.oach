# Markenbilder

Bilder der Marke für Einsatz außerhalb der App, z. B. als Projektbild in Taiga, in Präsentationen oder in Dokumenten.

| Datei | Inhalt |
|---|---|
| `favicon-512.png` | App-Symbol „M.“ auf dunkelblauem Grund, 512 × 512 px, transparente Ecken. Gerendert aus `frontend/public/favicon.svg`. |

Die Originale, die die App selbst verwendet, liegen in `frontend/public/`. Ändert sich das Logo (Story #54, kleines „m.“), werden diese Bilder neu gerendert.
